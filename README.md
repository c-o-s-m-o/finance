# Finance — Legacy

Projeto antigo de interface para controle financeiro, preservado como parte da evolução do meu portfólio.

> **Status:** legado / não ativo. Este repositório não representa minha arquitetura financeira atual nem meus projetos mais recentes.

## Contexto

O projeto foi iniciado como uma aplicação frontend voltada a finanças e organização de informações financeiras. A implementação está localizada em:

```text

└── finance/
```

## Por que este repositório continua público?

Ele registra uma etapa anterior de aprendizado em desenvolvimento web e mostra a evolução entre experimentos iniciais e sistemas mais estruturados desenvolvidos posteriormente.

## O que este projeto representa

- fundamentos de frontend;
- primeiros experimentos com uma aplicação financeira;
- evolução histórica da organização de projetos;
- transição para arquiteturas e aplicações mais completas.
